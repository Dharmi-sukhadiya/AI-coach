# 🚀 AI Resume + Interview Coach

AI Resume + Interview Coach is a full-stack AI-powered web application that helps job seekers improve their resumes, prepare for interviews, and strengthen their professional profiles.

The platform uses Google Gemini AI to provide personalized coaching, resume analysis, LinkedIn headline generation, and interview preparation tools.

---

## ✨ Features

### 🎯 AI Interview Coach
- Real-time interview practice
- Personalized feedback on answers
- Multiple coaching personas:
  - Tough Technical Interviewer
  - Empathetic Recruiter
  - Systems Design Interviewer

### 📄 ATS Resume Analyzer
- Resume profession detection
- ATS score calculation
- Missing keyword suggestions
- Resume improvement recommendations
- Formatting suggestions

### 💼 LinkedIn Headline Generator
- Generates professional LinkedIn headlines
- Role-specific recommendations
- Multiple headline options

### ❓ Interview Question Generator
- Profession-specific questions
- Multiple difficulty levels
- Technical and behavioral questions
- Sample answers included

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/Dharmi-sukhadiya/AI-coach
cd AI-coach
```

### Backend Setup

```bash
cd backend
npm install
```

Create a `.env` file:

```env
GEMINI_API_KEY=your_gemini_api_key
```

Start backend:

```bash
npm start
```

---

### Frontend Setup

```bash
cd frontend
```

Create a `.env` file:

```env
VITE_API_URL=http://localhost:3000
```

Run frontend locally using your preferred local server.
